# RESOLVE AI

A responsive problem-resolution workspace with Firebase Authentication, per-user Firestore history, a server-side Gemini endpoint and Android-installable PWA support.

**Start here:** read [`SETUP.md`](SETUP.md) before configuring or deploying.

- Website entry: `public/index.html`
- Styling: `public/style.css`
- Browser application: `public/app.js`
- Secure AI endpoint: `functions/index.js`
- Firestore rules: `firestore.rules`

This is a starter project, not a live or audited production service. It requires your own Firebase project and Gemini API key. Never place the Gemini API key in frontend files.
